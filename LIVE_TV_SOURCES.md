# Live Television and Broadcaster Discovery

Sources reviewed on 2026-11-26. Broadcasters can replace, end, restrict or retire streams. A public web player does not establish a reusable third-party integration. MovieExplorer embeds reviewed fixed YouTube videos and active videos validated through the official YouTube Data API for approved channels. Official viewing links remain available independently of the embedded player.

Actual in-app live playback was verified for NTV Kenya, Al Jazeera English and France 24 English in muted, isolated desktop Chrome. Each provider player displayed its native Live indicator and its reported playback position advanced. Playback was rechecked on 2026-11-26 during the refinement. An official TV47 candidate also played, but the native player showed a fixed 1:23:49 recording. It was excluded from live playback.

The station profile links to official schedules where established. The feature does not calculate programme times, poll listings, or show a current-programme label. Broadcast delivery goes directly from YouTube to the browser. Native player controls and branding remain visible. An embedded player reporting playback records a Recently Watched entry. External visits appear as Recently Opened.

The approved fixed embed sources work without a key while YouTube keeps them available. The NTV fixed event expires on 2026-11-29. Set the optional server-only `YOUTUBE_DATA_API_KEY` to validate fixed IDs and discover a replacement automatically. No valid key was configured for verification. Dynamic results were tested with fixtures. SIGnet remains an official viewing destination.

Public channel artwork is served from YouTube?s image host. No broadcaster logos are redistributed in this repository. MovieExplorer uses a text fallback when the source is unverified or the image fails. Resolved live thumbnails are displayed directly from YouTube and are not saved as artwork assets. Artwork remains subject to broadcaster and platform terms.

The resolver checks known video IDs before search, uses on-demand queries only and verifies the returned channel, current broadcast, public visibility, embed eligibility and known regional restrictions. Per instance, live results are cached for 60 seconds and confirmed absence for 90 seconds, with a 48-entry bound. A rolling 40-search limit and 15-minute quota backoff reduce repeated calls.
